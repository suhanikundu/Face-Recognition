# 🧠 Face Recognition & Emotion Detection

This project is an AI-based system that performs **real-time face recognition** and **emotion detection** using deep learning and computer vision. It takes webcam input, detects human faces, and predicts the emotional state of each face using a trained model.

---

## 📌 What This Project Does

- ✅ Detects human faces using a webcam in real time.
- 😃 Recognizes basic human emotions like **Happy**, **Sad**, **Angry**, **Surprised**, etc.
- 🧠 Uses a Convolutional Neural Network (CNN) trained on an emotion dataset (FER-2013).
- 📸 Displays the predicted emotion label on the live video feed.
- 🌐 Includes a web-based UI (HTML) to show visual output (optional).
- ⚡ Simple, fast, and easy to run on any machine with a camera.

---

## 📂 Files Included

- `trainmodel.ipynb` – Notebook for training the CNN model on emotion data.
- `emotiondetector.h5` – Trained model for emotion classification.
- `realtimedetection.py` – Python script to run real-time detection using webcam.
- `index.html` – Optional HTML for browser-based output display.
- `images/` – Folder to store any face/emotion sample images.
- `requirements.txt` – Dependencies to install via pip.
